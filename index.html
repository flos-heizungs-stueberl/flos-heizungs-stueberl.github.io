Hallo Welt

Dies ist eine einfache "Hello World"-Homepage, bereitgestellt über GitHub Pages.

Zum Veröffentlichen: Repository auf GitHub pushen und in den Einstellungen unter "Pages" den Branch main (oder gh-pages) im Ordner / (root) auswählen.

Wenn das Repository username.github.io heißt, wird die Seite unter https://username.github.io/ erreichbar sein; sonst unter https://username.github.io/repo-name.
